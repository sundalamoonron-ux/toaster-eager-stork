A program that writes the funniest error message a kitchen toaster
would show its owner, in 120 characters or fewer, to `/output/entry.txt`.

## The line

> ERROR: Toasting cancelled. The bread filed a complaint.

Deadpan, apologetic-adjacent, and absurd in exactly the way a real
appliance error message is not supposed to be: the bread is the one
filing the complaint. Chosen by a pairwise tournament over 10
candidate lines, judged on the competition's own criteria — a real
toaster error message, fresh (no obvious toast puns), tight (55
characters), one voice, landing on a single read.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (override with the `OUTPUT_PATH`
environment variable for local testing).
